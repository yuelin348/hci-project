# A Better Way to Access In-game Activity Information

人机交互课程研究项目主页 · **Creative and Magic**（李岳林，单人项目）

- 线上地址：<https://yuelin348.github.io/hci-project/>
- 源码仓库：<https://github.com/yuelin348/hci-project>
- 技术形态：纯静态 HTML / CSS，无 JavaScript、无构建步骤、无第三方资源。

## 这个页面是什么

一个用于展示 HCI 课程研究项目的单页主页，包含：

1. 团队介绍（单人研究者版式，研究者：李岳林）
2. 项目提案：以《创造与魔法》为研究场景，包含背景、工作假设、研究目标、研究问题与预期产出
3. 数据收集计划：正式访谈提纲（3 个主题 / 15 题）与正式问卷题目（4 个部分 / 15 题）
4. 四份匿名访谈记录（Participant 01–04），按 Topic 1–3、Q1–Q15 完整呈现
5. 十份匿名问卷回答、原始编码矩阵、开放题回答与 CSV 下载

页面用“游戏研究档案”的编辑设计语言，包含活动雷达概念界面、章节编号、材料状态标记和无障碍支持。页面不收集问卷、不包含后台。

## 当前内容

### 访谈

- **提纲**：3 个主题、15 个问题及研究目的；
- **记录**：Participant 01–04 的 60 组问答按原始回答录入，保留口语表达，未改写回答内容；
- 页面按 Q1–Q15 编号组织每位参与者的回答，并在概览表中呈现游玩侧重与关键信息困难。

### 问卷

- **问卷题目**：4 个部分、15 个问题，问题与选项均按原始材料录入；
- **回答**：R01–R10 共 10 份匿名回答；Q1–Q14 以原始字母编码呈现，Q15 单独展示；
- **原始数据**：`assets/survey-responses.csv`，每位受访者一行，Q1–Q14 保存字母编码，Q15 为开放文本；
- **分析边界**：样本量 n=10，页面描述仅针对这组课程样本，不做总体推断。

### 需要特别说明的数据情况

- 问卷 **Q5、Q13 为多选题**，原始回答中保留了多个选项：
  - Q5：R02（`BD`）、R03（`AD`）、R04（`BDE`）、R08（`BE`）；
  - Q13：R01（`BCE`）。
- 页面与 CSV 均按原始回答保留，数据口径说明也显示在页面 05 章节。
- **Q15 为开放题**：仅 R03 填写补充想法——“希望不要太杂乱吧，也许让我自定义展示的项目？”其余 9 位未填写。
- 页面没有公开可识别受访者信息。

| 04 `P01`–`P04` | 四份匿名访谈记录 | 如受访者修正回答，同步更新 |
| 05 统计卡与条形图 | 由十份回答计算 | 新增回答后需重算百分比 |
| 05 原始编码矩阵 | R01–R10 × Q1–Q14 | 与 CSV 保持同步 |

| `assets/survey-responses.csv` | 十份回答的原始编码 | 新增回答时补行并同步 HTML 表格 |

注意：

- 公开页面和仓库会公开源码与所有数据。上传新材料前必须匿名化，不要包含姓名、联系方式、原始录音或可识别细节。
- 原始访谈材料与匿名编号对应表只应保存在本地，不进入仓库。
- 问卷字母编码按题目选项从上到下依次对应 A、B、C…；新增回答时不要重排已有选项。
- 新增问卷回答后，需要同步更新页面上的统计数字、图表、编码矩阵和 CSV。
- 修改布局或新增长回答后，请重新检查手机端布局、表格滚动与打印效果。

## 设计与可访问性说明

- 语义化 landmarks、正确的标题层级、跳转主内容链接；
- 原生 `<details>` 折叠，无需 JavaScript 即可键盘操作；
- 表格带 `<caption>`、列/行 `scope`，数据区可聚焦横向滚动；
- 文字与背景颜色按 4.5:1 对比度目标设计；
- 支持 `prefers-reduced-motion`；
- 提供打印样式，适合导出 PDF；
- 不使用外部字体、图片、脚本或追踪器。
