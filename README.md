# A Better Way to Access In-game Activity Information

人机交互课程研究项目主页 · **Creative and Magic**（单人项目）

- 线上地址：<https://yuelin348.github.io/hci-project/>
- 源码仓库：<https://github.com/yuelin348/hci-project>
- 技术形态：纯静态 HTML / CSS，无 JavaScript、无构建步骤、无第三方资源。

## 这个页面是什么

一个用于展示 HCI 课程研究项目的单页主页，包含：

1. 团队介绍（单人研究者版式）
2. 项目提案：以《创造与魔法》为研究场景，包含背景、工作假设、研究问题与预期产出
3. 数据收集计划：正式访谈提纲 + 10 份匿名问卷的题目结构
4. 三份匿名访谈记录（Participant 01–03），按 Topic 1–3、Q1–Q15 完整呈现
5. 十行匿名问卷示例数据表、示例摘要与 CSV 下载

页面用“游戏研究档案”的编辑设计语言，包含活动雷达概念界面、章节编号、材料状态标记和无障碍支持。页面不收集问卷、不包含后台。

## 内容维护清单

| 位置 | 当前内容 | 后续动作 |
| --- | --- | --- |
| 团队卡 `.researcher-card` | “研究者姓名”占位 | 替换为可公开的姓名 / 昵称 |
| 项目信息 `.project-facts` | 联系方式、状态 | 补充课程信息与联系信息 |
| 03 访谈提纲 | 正式版，3 个主题 / 15 题 | 如题目有修订，同步更新页面 |
| 03 问卷题目 | 结构示例 | 用正式题目与选项替换 |
| 04 `P01`–`P03` | 已录入的匿名回答 | 如受访者补充或修正回答，同步更新 |
| 05 统计卡与条形图 | 由示例 CSV 计算 | 按正式 CSV 重新计算 |
| 05 表格 `R01`–`R10` | 示例数据 | 替换为十份匿名问卷回答 |
| `assets/survey-sample.csv` | 示例 CSV | 替换为正式匿名数据，并同步调整表头 |
| `.sample-tag`、`.sample-notice`、`.materials-status` | 问卷待更新提示 | 正式问卷材料到位后删除或改为完成状态 |

注意：

- 公开页面和仓库会公开源码与所有数据。上传新材料前必须匿名化，不要包含姓名、联系方式、原始录音、可识别细节。
- 原始访谈材料与匿名编号对应表只应保存在本地，不进入仓库。
- 如果正式问卷字段发生变化，需要同步修改 `index.html` 中的表头、字段说明和统计口径。
- 替换布局内容或新增长回答后，请重新检查手机端布局、表格滚动与打印效果。

## 设计与可访问性说明

- 语义化 landmarks、正确的标题层级、跳转主内容链接；
- 原生 `<details>` 折叠，无需 JavaScript 即可键盘操作；
- 表格带 `<caption>`、列/行 `scope`，数据区可聚焦横向滚动；
- 文字与背景颜色按 4.5:1 对比度目标设计；
- 支持 `prefers-reduced-motion`；
- 提供打印样式，适合导出 PDF；
- 不使用外部字体、图片、脚本或追踪器。

## 问卷示例数据口径

- 样例样本：10 份匿名问卷；
- 汇总值与 `assets/survey-sample.csv` 保持一致（70% 近三个月错过活动、平均满意度 3.0/5、4/10 最想要统一时间线、社群/群聊 6/10 为最常见发现渠道）；
- 多选题比例按选择人数 / 10 计算，因此合计可超过 100%；
- 这些数字仅用于版式展示，不作为研究结论或总体推断。
