02

Project Proposal / 项目提案

问题不在“有没有活动”，
而在“我有没有看见”。

我把注意力放在活动被发现、被比较、被记住的整个过程，而不仅是信息是否存在于某个页面。

活动的信息并不少。
难的是，在正确的时间，
遇到正确的信息。

Background / 项目背景

在《创造与魔法》这类持续运营的多人游戏中，限时活动、赛季任务、公会安排与商店刷新构成了并行的时间表。玩家通常需要同时处理游戏内公告、社群消息、内容平台与第三方数据库。信息虽多，却缺少统一的时间视角与优先级判断。

当玩家错过一个想参加的活动，损失的往往不只是一份奖励，还有对“下次一定不会错过”的控制感。

Research aim / 研究目标

理解《创造与魔法》玩家如何发现、判断并安排游戏内活动，识别“想参加却错过”的关键情境，并把研究中的线索转译为信息组织、提醒节奏与优先级表达的设计启示，而不是制造更多提醒。

Working assumptions / 工作假设

以下不是研究结论，而是访谈与问卷希望检验的三个方向。

HYPOTHESIS / A

信息分散

活动信息散落在公告、邮件、群聊、短视频和 Wiki 中，玩家需要重复确认，甚至自己维护清单。

FRAGMENTATION

HYPOTHESIS / B

时机错位

信息出现时，玩家可能正在工作、离线或在另一台设备上；等到再次打开游戏，活动窗口已经关闭。

TIMING GAP

HYPOTHESIS / C

决策负担

即使看到了活动，玩家仍需判断优先级、参与门槛与时间成本。过多提醒则会演变成新的噪音。

DECISION LOAD

Research questions / 研究问题

我想回答的三个问题

  1. RQ1

    《创造与魔法》玩家目前通过哪些渠道发现、确认并记住周期性副本与限时活动？哪些渠道真正有效？

  2. RQ2

    哪些情境会导致“想参加却错过”？玩家会采取什么补救或绕行策略？

  3. RQ3

    怎样的信息组织与提醒方式能降低信息负担，而不是制造新的打扰？

Expected outcomes / 预期产出

从理解行为，到形成可被设计使用的线索。

  1. 01 / UNDERSTAND

    活动发现旅程

    梳理玩家从“得知活动”到“决定参与”的关键触点与断裂位置。

  2. 02 / IDENTIFY

    错过场景清单

    总结时间、渠道与注意力层面的典型错过情境，以及玩家已有的绕行策略。

  3. 03 / TRANSLATE

    设计启示

    把研究发现转译为关于统一活动视图、提醒节奏与优先级表达的设计建议。

范围说明 — 研究以《创造与魔法》为具体场景，关注周期性副本与限时活动的信息发现和时间管理，不评估游戏数值平衡；问卷部分的示例数据不作为已验证结论。

正式访谈提纲

本次访谈属于人机交互课程项目，旨在了解《创造与魔法》玩家在参与周期性副本及其他游戏活动时的参与习惯、信息获取方式和实际体验。

访谈没有标准答案，我们希望了解你的真实经历、个人习惯和看法。所有回答仅用于课程研究与分析，不会用于商业用途。访谈记录将以匿名方式整理。如果你不方便回答某个问题，可以选择跳过。

感谢你的参与！

TOPIC 01 / GAMING ACTIVITIES AND PARTICIPATION HABITS

游戏活动与参与习惯

研究目的：了解玩家在游戏中的日常行为、活动选择方式，以及影响其参与决策的因素。

  1. Q1

    你平时在《创造与魔法》中最喜欢参与哪些类型的活动或玩法？为什么？

  2. Q2

    你登录游戏时通常会做些什么？能不能描述一次比较典型的游戏过程？

  3. Q3

    面对游戏中种类繁多的副本和玩法，你通常依据什么决定参与哪些活动？

  4. Q4

    有没有一些你曾经经常参与，但后来逐渐减少参与甚至放弃的活动？是什么原因导致这种变化？

  5. Q5

    当你游戏时间有限时，你通常如何安排自己的游戏内容？有没有遇到过计划被打乱的情况？

TOPIC 02 / GAME INFORMATION ACCESS AND MANAGEMENT

游戏信息获取与管理经历

研究目的：了解玩家如何获取、理解和使用游戏活动信息，以及现有信息渠道存在的问题。

  1. Q6

    当你第一次接触一个不熟悉的副本或玩法时，通常会如何了解它？可以描述一下从产生兴趣到真正参与的过程吗？

  2. Q7

    在长期游玩过程中，你有没有形成自己判断活动刷新规律或活动状态的方法？能具体讲讲吗？

  3. Q8

    能不能回忆一次你原本打算参与某项活动，却因为缺少某些信息而改变计划的经历？

  4. Q9

    你从游戏公告、社区帖子、其他玩家等渠道获取信息时，通常如何判断这些信息是否准确、是否仍然有效？

  5. Q10

    当你在游戏过程中需要确认某项活动的信息时，实际会经历哪些步骤？有没有哪个环节让你觉得特别麻烦？

TOPIC 03 / GAMING EXPERIENCE AND INFORMATION NEEDS

游戏体验与信息需求

研究目的：探索活动机制和信息获取方式对玩家体验的影响，并了解玩家对信息辅助方式的真实期待。

  1. Q11

    游戏中不同副本和活动采用不同的刷新周期，你觉得这种设计对自己的游玩体验有什么影响？

  2. Q12

    有没有过这样的经历：原本只是想上线放松或随便玩一会儿，却因为活动时间、地点或其他安排而需要额外花费精力？请具体描述。

  3. Q13

    如果游戏中的活动信息能够更容易地被找到，你认为这会对自己的游戏过程产生什么变化？为什么？

  4. Q14

    在游戏过程中，你觉得哪些活动信息应该比较容易随时查看？哪些信息只需要在自己主动查询时才出现？为什么？

  5. Q15

    如果可以改善游戏目前的信息获取方式，你最希望改变什么？有没有什么设计是你明确不希望出现的？

METHOD / 02 · QUANTITATIVE 结构示例 10 匿名问卷 5–8 分钟 · 线上填答 · 10 份有效样本 · 匿名编号 +

问卷题目结构（示例）

问卷用于补充覆盖面：获取渠道、错过频率、满意度与需求排序。正式题目将围绕《创造与魔法》，并以匿名编号回收回答。以下是题目结构示例。

PART A / 基本信息

年龄段、每周游戏时长、主要游玩平台。

均为单选，选项覆盖常见区间。

PART B / 获取行为

你通常通过哪些渠道获取活动信息？（多选）

游戏内公告 / 社群与群聊 / 短视频与直播 / Wiki 与数据库 / 朋友告知。

PART C / 体验评价

“我总能及时知道当前正在进行的活动。”请用 1–5 分评价。

另有信息清晰度、跨渠道确认负担、提醒打扰程度等陈述。

PART D / 错过经历

过去三个月内，你是否错过过想参加的游戏活动？

若回答“是”，继续勾选情境与原因，并填写一段简短描述。

PART E / 需求排序

你最希望活动页面优先解决什么？

统一时间线 / 活动提醒 / 个性化筛选 / 朋友动态，并开放一题补充想法。

Research ethics / 研究伦理

先保护参与者，再谈研究结果。

  • 访谈前说明研究目的、数据用途与记录方式，取得明确同意。
  • 公开页面只使用 Participant 编号，不出现真实姓名、联系方式或可识别细节。
  • 原始访谈材料与编号对应关系仅保存在本地，不随网页或公开仓库发布。
  • 参与者可随时退出；涉及个人的回答不进入公开展示。
